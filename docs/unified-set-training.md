## 已确认结构

- 卡牌、敌人、药水、遗物逐实体；玩家与全局一个实体。类型专用投影及类型 embedding，统一64维，无槽位位置编码。
- 4层SAB，4头，每头16维；Pre-LN，FFN 64→128→GELU→64，残差；编码器末尾LayerNorm。无dropout。暂不用ISAB。
- PMA一个可学习查询汇总全部有效实体；摘要64维经线性层成为决策q，同时供Critic读取。
- 动作类型16维、来源64维、目标64维，拼接144→128→64产生候选k；分数q·k/8。统一候选分布，环境mask在softmax前施加。
- 无目标用可学习表示；出牌引用卡牌/敌人，药水引用药水/敌人，结束回合引用玩家/无目标。候选引用只作索引，不作token特征。
- 动态实体批次补齐；不保留原64张模型限制。沿用公共后端512动作外部切段和其容量证明，保留完整最终观测及自举。
