# 最小切片 PPO+MLP 冒烟计划

修订日期：2026-09-08。执行依据：`spec-v6.md` §7–§10 与
`docs/decisions.md` D25/D27。本计划只验证学习主链路能在 `minimal-v1` 的 battle 任务工作，不把简单环境
上的结果冒充中等档 Gate 3，也不提前训练 Set Transformer。

## 1. 为什么现在做

当前 A0 三遭遇、三类卡的实体观测、动作掩码、奖励、确定性和稳定性已经验收。先在这个
固定切片接通 MLP 与 PPO，能建立一个已知可学习的检查点；此后按机制批次扩容，首次出现
退化时便有相邻版本可比较。

但当前随机策略并不弱：10000 个配置中为 8711 胜，Two Louse 为 3333/3333 胜。
因此只比较胜率会漏掉策略通过少掉血获得的改进。冒烟以 D27 `battle_reward_v1` 逐局总回报为主，同时保留
胜率、终局 HP、遭遇分桶和训练诊断。

## 3. 固定实验边界

- 环境：`minimal-v1`，只含 Jaw Worm、Cultist、Two Louse 与 Bash/Defend/Strike。
- 输入：`FlattenWrapper` V2；类别只能经模型内 embedding，不能把 ID 当连续数。
- 连续值：模型内固定尺度按 D25 S2 约定，不裁剪、不从评估 seed 拟合；checkpoint格式
  升为2，包含 numeric encoding version和尺度，旧格式显式拒绝。
- 动作：31 位扁平动作；非法动作在 softmax 前屏蔽，log-prob、熵和 ratio 全部基于
  屏蔽后的分布。
- 奖励：D27 `battle_reward_v1`，非终局 0；胜利 `1 + 0.5 * hp_exit/max_hp_exit`；失败和硬超时 0；`gamma=1`、`beta=0`。
- seed：训练和开发诊断均为 `>=100000` 的不重叠区间；`eval_seeds.json` 保持不变，
  不参与反复调参。
- 对比：MLP 与随机 Agent 都只读同源观测及环境 mask。最终诊断固定模型初始化、采样
  RNG、训练预算和诊断配置，并逐遭遇配对。

## 4. 扩容后的回归方式

中等档不一次性开放。M1 卡表与动作语法审计完成后，把卡、敌人与新观测字段按机制簇
组成批次，并在 `docs/decisions.md` 锁定批次边界。每批按同一顺序执行：

1. 新机制单测、规范观测和动作闭环回归；
2. 旧批次完整回归，确认没有基础语义回退；
3. 相同初始化、seed 方案和训练预算下从头执行短训；
4. 与上一批比较回报、熵、explained variance、失败轨迹和吞吐；
5. 通过后才进入下一批，失败则停在首次分叉批次排查。

warm-start 结果可以帮助判断表示迁移，但不能替代从头训练，因为它会把上一批已经学到
的策略带入新环境，掩盖新状态是否能独立学会。

## 5. 完成与非完成

完成 S5 只能说明：当前环境、Flatten 输入、MLP、masked PPO 和评估闭环已有一个可复现
的最小工作样例。它不说明中等档可学，不说明 Set Transformer 正确，也不说明两种架构
在简单环境上必然等效。Set Transformer 仍在中等档 MLP 主链路稳定后实现，并按 Gate 4
完成正式配对对照。
