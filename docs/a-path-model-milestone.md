# A路径模型与Agent里程碑

2026-09-13。独立分支codex/a-path-agent，基于已推送的615cffa。完成模型与公开动作接口的第一批工程验收，尚未完成整个A路径任务书。

## 做了什么与解决的问题

- 实施四层SAB＋PMA与两阶段Pointer，不再对raw来源分数加目标分数做完整动作softmax。PMA摘要同时供Value和END_TURN评分，目标Query来自具体来源。
- 合法候选保留具体副本、目标及快照，双向映射唯一；SELECT_CARD旧效果来源引用正确解释为NO_TARGET。真实选牌在结算后使用新观测，来源和目标内部选择不额外推进环境。
- 联合logp相加，一次PPO ratio/clipping；精确熵含所有条件分支及可导来源权重。测试用枚举oracle核对熵及梯度，不能用两个独立clip替代联合目标。
- 公开结算上下文进入PLAYER_GLOBAL投影及共享编码器，使来源与PMA均可读取。沿用扣牌关系融合、区域未知属性边界及类型专用投影。
- 修复终局完全空候选无法打包计算Value的问题；补回关系引用与注意力资源检查，不通过删实体解决超限。
- 首轮新测试12通过、2失败：Dual Wield夹具只有一个可复制攻击，环境正确自动结算；已改为多候选夹具。另一处是真实数值缺陷：全空行回退位置的无效NaN污染梯度，现于softmax前清零所有无效输入。
- Agent仅接收观测，不持有环境对象；更新可使用保存的样本与动作，无需当前环境。采样RNG可往返恢复，但完整训练恢复尚未实现。
