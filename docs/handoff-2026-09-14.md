## 一、项目目标

### 1.1 总目标

按 `spec-v6.md`（唯一执行依据）：以锁定的 `sts_lightspeed` C++ headless STS1 Ironclad 战斗后端（Python 保留教学/规范层）为载体做强化学习工程实践——随机/规则两条基线 → A 阶段 Set Transformer + PPO → B 阶段 Decision Transformer，A/B 对照即产出；真实目标是通过工程实践理解 Transformer 原理。

### 1.2 本轮阶段目标

- 环境扩展：Ironclad 全卡（75 类、150 个基础/升级版本）、第一/二/三幕敌人扩展接入；药水与遗物维持各自入口既有范围；统一在 A20 战斗开发环境内。
- A 路径：四层 SAB（64 维、4 头、FF128、Pre-LN、GELU、dropout 0、FP32、单 seed PMA）＋两阶段来源/目标 Pointer 采样、一次 `env.step`、联合 PPO；工程验收后按"最多三个初始化各 262144 步、训练评估总上限四小时"完成受限训练与评估。
- 交付形态：每个里程碑报告完成项、问题与未完成项；基准提交并推送 `origin/main`。
