## 一、立即锁定这些决定，不再向我询问 A 还是 B

1. 使用 A 路径：模型内部先选择“具体牌/具体药水/结束回合等操作”，需要目标时再以所选来源选择敌人，参数选齐后只调用一次 `env.step(complete_action)`。

3. 使用共享 Set Transformer，保留 PMA 全局池化和 Critic。已有合格主干就复用；没有时按任务书小型默认配置实现，不擅自加层。
4. 出牌、耗尽、弃牌、取牌、药水等按操作语义使用不同可学习 task Query；同类任务共享参数。候选实体表示必须已经包含局势/阶段上下文，不另外强制创建重复的 c 网络。
5. 第一阶段将所有合法的具体来源操作和特殊操作的 raw logits 放在同一个 softmax 中。不先分别归一化牌和药水，也不新建“出牌还是药水”的第三层决策。
6. 第二阶段 Query 来自已选来源实体；敌人提供 Key。攻击/对敌技能/对敌药水可以共享目标评分模块。动作头 logits 后不再乘 V；编码器和 PMA 里的 V 正常保留。
7. NO_TARGET 是独立语义；对应条件概率1、目标logp0、目标熵0，不能把enemy0当无目标。
8. PMA 的 g 同时供 Value 和合法特殊动作的标量评分，例如 END_TURN；Value 不是结束回合分数。
9. 完整 logp = 来源 logp + 条件目标 logp。PPO只计算一个联合ratio并裁剪一次。**旧的 raw `b_source+t_target` 全局softmax方案已作废，不要重新实现。**
10. 真正出牌结算后触发的耗尽/弃牌/随机候选选择，仍是环境现有的新决策状态。A路径不允许越过已发生的结算继续使用旧观测。

## 三、实现要求

### 候选与动作路由

- 合法性来自既有环境/上游候选，不重新写游戏规则。
- 第一阶段按“操作种类+具体来源+必要模式”分组；同一攻击牌有多个敌人目标时只出现一次。
- 需要目标的来源必须有至少一个合法目标。无目标来源只有一条语义路径。
- `完整env_action ↔ (source, target/NO_TARGET)` 双向唯一，覆盖现有全部合法动作；不要将不同卡副本按card_id合并。
- 牌/药水/敌人重排时同步路由，数组索引只作路由，不进入实体语义embedding。
- 本地已有的耗尽、弃牌、取牌、生成候选、多选阶段均接入本轮模型，并保留其已有环境计步与结算契约。真正未实现的环境机制列缺口，不能假装接通。

### 模型和分布

- 每次来源+目标决策共享一次编码结果H；不为每个候选重跑Transformer。
- 明确实现 act / evaluate_actions / value_only 或本地等价接口。
- evaluate_actions固定历史来源和目标；不得重新抽样，不得使用正在运行环境的新状态来恢复旧mask。
- 实现精确联合熵：`H(source) + sum_source p_source * H(target | source)`，含所有合法来源，当前权重不detach。无目标分支熵为0。
- 可导出正确联合概率用于诊断/兼容，但不能把旧raw联合评分混回来，也不要让正式采样退化成一次完整动作multinomial。
- mask全false、唯一目标、padding、终局Value-only均不得产生NaN。默认dropout0、FP32。
- 条件目标的来源向量不得detach；参数更新要能影响共享编码器、任务Query、目标投影、PMA和Value。

### PPO、轨迹和恢复

- 保留已有PPO损失与GAE的正确数学；改必要的模型/环境/数据入口绑定，不删reward contract检查来凑运行。
- 每条真实transition保存不可变观测、候选/mask映射、完整动作与分解、旧联合logp、旧Value和终止/截断信息。
- rollout采样不存计算图；更新时重算编码，不只缓存detached embedding。
- Advantage、old_value、return_target、old_logp在一批epochs内固定。
- 真实终止不bootstrap，外部截断用reset前最终观测bootstrap，GAE不跨reset。内部参数选择不插入transition。
- source/target采样、数据抽样、shuffle、CPU/CUDA RNG、模型/优化器/进度与环境恢复信息全都保存和校验。
- 新策略分布与checkpoint版本独立登记。旧MLP路径可复现；不把旧checkpoint伪装成新格式。
