# Week 4 T5：完整路径稳定性、确定性与性能结果

验收日期：2026-09-05。结论：**工程与理解验收均通过。** 本文只记录
T5，不替代 T6 的 Gate 1 总结，也不据此宣称当前模拟器已与正版 STS1 全机制等价。

## 1. 可复跑入口与测量口径

运行入口：

```powershell
python scripts/run_week4_t5.py --episodes 10000 --repeats 3 `
  --warmup-episodes 100 --determinism-episodes 60 `
  --output build/week4-t5-acceptance.json `
  --worktree-patch build/week4-t5-worktree.patch
```

- 唯一配置数为 `10000`，seed 为 `100000..109999`；Jaw Worm / Cultist /
  双虱分别为 `3334 / 3333 / 3333` 场。每条路径重放整套配置，所以每轮共
  `40000` 个 path-episode；性能重复 3 轮，共实际执行 `120000` 个
  path-episode。
- 每个配置有独立的 Agent seed `20260905000..20260914999`。四条配对路径每次
  从相同 Agent seed 开始；环境 RNG 与 Agent RNG 分离。Agent 依 D23 产生
  `probabilities[31]` 并在内部抽出 `action:int`；验收 runner 只校验、转交与记账，
  不持有抽样 RNG、不重算合法动作。
- 所有常见数值库线程变量固定为 1。每条路径先预热 100 场；正式秒表计入 reset、
  原始/规范/wrapper 观测转换、Agent masked softmax 与抽样、decision 校验、runner
  控制流、`env.step` 和统计记账；不计进程启动、预热、逐步确定性序列化和结果写盘。
- `raw-pybind` 为了接 D23 Agent，仍需把 C++ 的 31 个布尔值转换成 NumPy mask，
  该转换已计时。因此这是原始接口的**完整 Agent 闭环**，不是此前只测后端 step 的
  约 11.7 万步/秒口径。

## 2. 稳定性与奖励

四条路径三轮的统计完全一致。每一轮每条路径均为：`10000` 场、`184117` 步、
`8711` 胜、`1289` 负；异常 `0`，非法动作 `0 / 184117 = 0%`，硬超时
`0 / 10000 = 0%`，D18/D20 奖励检查失败 `0`，累计奖励
`11403.574952483177`。

| 遭遇 | 场数 | 步数 | 胜 / 负 | 异常 | 非法动作 | 硬超时 | 奖励检查失败 | 累计奖励 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| Jaw Worm | 3334 | 78398 | 2844 / 490 | 0 | 0 | 0 | 0 | 3553.5937505960464 |
| Cultist | 3333 | 63194 | 2534 / 799 | 0 | 0 | 0 | 0 | 3194.6374592781067 |
| 双虱 | 3333 | 42525 | 3333 / 0 | 0 | 0 | 0 | 0 | 4655.343742609024 |

奖励检查逐场要求：非终局奖励全为 0；正常失败与硬超时累计为 0；胜利累计值为
`1 + 0.5 * player_hp / player_max_hp`；任务终局必须 `terminated=true`、
`truncated=false`。本次没有硬超时样本，硬超时奖励分支由既有单元测试覆盖，本表
不伪称在 10000 场里实际观察到了超时。

## 3. 确定性

从同一配置集中分层取 60 场（每种遭遇 20 场），每条路径各重跑两次。固定序列化
按显式字段顺序、shape、dtype 和小端字节序生成；运行时间、机器信息等元数据不进入
载荷。每一步比较动作前与 `step` 返回的下一观测、完整 action mask（包括终局全
False）、实际动作、奖励、`terminated/truncated` 以及排序后的允许 `info`。

- 四条路径各自表示的重放失败：`0`。
- 跨四条路径的规范语义、mask、动作、奖励、标志及 info 差异：`0`。
- Flatten 与 Token 的路径表示不同，只比较其可追溯到的规范语义；没有把不同表示
  宣称为逐字节相同。

每轮均执行同一套 10000 配置和 184117 步。中位数用于降低偶发系统抖动的影响，
