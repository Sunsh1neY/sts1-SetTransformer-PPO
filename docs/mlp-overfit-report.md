# D25 S2：MLP 小样本过拟合验收

日期：2026-09-08。依据：`docs/decisions.md` D25 S2 运行前约定与
`docs/mlp-smoke-plan.md`。结果：S2工程验收通过，下一步是S3 PPO接入。

## 1. 这次实验回答的问题

让同一个 MLP 反复读取一小批观测，学习两种标签：随机策略当时实际选择的合法动作、
该轨迹从当前位置开始的实际累计回报。这是监督记忆诊断，检查输入、动作路由、反向传播、
优化器及两个输出头能否共同工作。它不衡量新局泛化，也不能据此断言 MLP 优于随机策略。

数据来自正式最小C++切片三遭遇各8局，共24局（19胜5负），环境seed为200000..200023，
Agent seed为300000..300023；选样seed为400000。每种遭遇抽16个原始非终局观测，共48个，
每个至少有两个合法动作。另对33个观测交换不同手牌及动作标签，得到81条样本。
增广配对的mask完全相同、标签不同、回报相同；它是输入路由探针，不是新增33局环境经验。

原观测和标签经24局完整重放逐字段核验；回报为gamma=1的单次Monte Carlo样本，失败为0，
最大为1.48125，含15种不同回报。单局各步回报相同符合当前仅终局发奖励的契约；不把
单条轨迹回报当作该状态价值的精确期望。

## 2. 防止简单捷径造成假通过

| 仅凭什么选择动作 | 本数据集能达到的准确率 |
|---|---:|
| 总选出现最多的动作 | 30.86% |
| 只看mask，对每种mask选出现最多的标签 | 最高43.21% |
| 在合法动作上均匀随机 | 期望18.08% |
| 完整观测的MLP，训练完成后 | 100% |

第二行是同批数据中任何仅依赖mask的确定性策略的准确率上界。33个换位对均全部学对，
说明模型使用了观测内容；这仍是训练样本记忆结果，不能替代未来Set模型对任意换位的
结构等变性验收。

## 3. 运行前固定的门槛与结果

固定 CPU 单线程、Adam学习率0.001、全批量1500次更新；优化目标为policy NLL + value MSE。
没有选择中途最好的checkpoint，也没有按结果放宽门槛。模型初始化seed分别为
500000、500001、500002；第一种初始化另完整重跑一次。

每次要求：动作准确率>=99%；换位对全对；policy NLL降至初值10%以内；value MSE<=0.001
且降至初值10%以内；梯度有限，非法概率为0，checkpoint重载输出完全一致。

| 初始化seed | policy NLL：初始→1500步 | value MSE：初始→1500步 | 动作/换位对准确率 | 判定 |
|---|---:|---:|---:|---|
| 500000 | 1.72644 → 0.00021537 | 1.03820 → 0.00085089 | 100% / 100% | 通过 |
| 500001 | 1.72583 → 0.00021165 | 1.24184 → 0.00000001530 | 100% / 100% | 通过 |
| 500002 | 1.72950 → 0.00023288 | 1.28101 → 0.00000002612 | 100% / 100% | 通过 |

各遭遇训练准确率均100%。第一组value MSE明显高于另两组，但仍低于预设门槛；完整曲线
保留在report.json，不将该训练过程描述为误差单调下降。第一组重跑的数据字节、每次
记录的指标和最终权重均完全一致。本机三次训练加一次重跑共约47秒，非跨机器性能保证。

## 4. 数值与checkpoint修正

原始HP等数值直接进入tanh会在初始化时出现饱和。本轮按D25事先登记的固定尺度在模型内
缩放，类别/one-hot保持原含义，没有裁剪或使用评估统计量。回归检查固定样本的全局投影
未饱和，HP与energy对value存在有限非零梯度。

checkpoint格式升为2，加入数值编码版本与尺度，并核验存储的尺度buffer；词表容量不足、
注册表版本不符及尺度篡改均显式拒绝。所有三份权重重载后的logits/value逐元素一致。
