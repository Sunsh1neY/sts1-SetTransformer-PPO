3. 动作：环境提供合法mask；死亡/倒地/召唤/扣押/反应换意图后立即更新；排序不改变目标。
4. 结算：胜利只奖励一次，阶段转换不提前结束，截断保存final_obs，异常不当失败0；battle_reward_v1不变。
