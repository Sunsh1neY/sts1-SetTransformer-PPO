## 接口和机制变化

- 观测 ironclad-enemy-observation-v2；环境契约 ironclad-enemy-integration-v2；模型统一接口 unified-enemy-entity-interface-v2，模型 unified-enemy-entity-set-v2。实际指纹见 act2-completion-fingerprints.json。
- CARD由115变116，仅因为已批准stasis区域增加一个类别；ENEMY由771变774，增加已批准NONE/PHASE_1/PHASE_2三类阶段。类型投影后仍为64宽；输入按有效实体动态组织。
- stasis卡首版只输出公开牌名。升级、费用及动态实例属性均不读取隐藏真值；编码在stasis区域仅激活身份和区域，其余分量统一表示该区域下未知，不能解释为已知数值0。普通卡字段不受此遮罩影响。
- 单一holds_card关系，通过不透明引用派生held_card_index。一次CARD→ENEMY融合位于原自注意力之前，带关系存在标志、无偏置Linear(65,64)、零初始化，共4160参数；不存在关系时增量严格为零。保留独立CARD token，不改变动作头/价值头结构，不创建第二套选择协议。
- 模型路线上的普通候选采用带snapshot的动作路由封装。快照推进后旧动作拒绝，置换实体仍保留原候选路由。后端构造新怪物时分配新实例引用，引用不进入语义张量；同实例不重新构造时保留引用和自然moveHistory。
- 不新增Minion、Painful Stabs、Stasis状态特征。第一勇士只在愤怒行动实际执行后标记公开PHASE_2，不直接输出隐藏AI标志。
- Flight递减改为扩展开关内队列动作，避免同张多段卡提前解除减伤；新实例校验防止延迟动作误作用于同槽替换者。五段Pummel+1定点实际总伤害5，之后Flight清除并眩晕，后续恢复4层。
- 真终局调用后端exitBattle，并设置单场返回控制回调，避免意外进入下一战。info.battle_exit输出实际牌组计数差与金币差；击杀盗贼的已偷金币在出口收回，逃跑部分不收回。外部截断不产生battle_exit。奖励仍为battle_reward_v1。
- 终局观测不再保留随从、扣牌关系或stasis卡；这不意味着对每个随从额外执行玩家击杀奖励钩子。
