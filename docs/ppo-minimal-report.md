相同300个环境seed，三遭遇各100；每局两策略使用相同的独立Agent RNG seed。

## 3. 训练监控与尚存限制

策略熵由首轮约1.4126降至末轮0.7544，末轮value loss约0.000557，近似KL约5.66e-8。
末轮grad norm约0.3866；记录的是裁剪前范数，不能将早期大于0.5的读数误认为未裁剪。

**价值估计仍需诊断**：末轮explained variance为-0.2573，训练中多次为负。value loss较小
不等于已准确区分状态价值；高胜率下回报变化小也是需要进一步检查的因素，当前没有
据此判定唯一原因。S4继续保留该指标及分桶回报，不以策略改善掩盖value拟合弱项。

本次证明最小切片的一条PPO+MLP学习管线有效；不证明跨初始化稳健、中等档可学、最优
策略、Set Transformer正确或游戏全机制等价。工程完成不自动代替用户理解复盘。
