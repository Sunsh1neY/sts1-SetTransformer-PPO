## 6. A：将行为与曲线对应起来

在同一横轴上定位 32／128／256 轮，并强调一个 iteration 内顺序是“先采样，后更新”。
第 k 轮训练回报来自本轮更新前的策略；checkpoint-k 保存更新后的模型，不是严格同一时刻。

按下面顺序逐组讲，每组先让用户描述趋势，再解释。tag 名已从当前写入代码核对，
实际历史 event 的存在和范围还需检查；JSONL 可作为数值核对来源。

| 指标／来源 | 项目中的准确读法 | 不可直接推出的结论 |
|---|---|---|
| mean_return | 当前 rollout 内完成 episode 的总奖励均值；不是整个历史累计均值 | 不是固定开发集表现，也不保证每局改善 |
| win_rate | 同一批完成 episode 的胜率 | 100% 不代表最优，HP 仍可提升 |
| entropy | 每次更新 minibatch 的分布熵，再对更新记录取均值；自然对数单位 | 下降不自动等于进步或探索失败 |
| learning_rate | 当前轮使用的线性退火学习率 | 末期更新小不必然代表已经收敛 |
| approx_kl | 更新 minibatch 中相对采样旧策略的近似 KL，再平均 | 不是训练初始与最终模型的距离 |
| clip_fraction | 概率比超出 [0.8,1.2] 的样本比例，再平均 | 0 不代表完全没有梯度／参数更新，也不等于实际被截断的目标项比例 |
| policy_loss | 含优势归一化与 PPO clipping 的代理目标 | 不可按监督学习 loss 单调下降标准判断策略好坏 |
| value_loss | 已含 0.5 的、启用 value clipping 的平方误差目标，更新期间平均 | 小不代表能准确区分不同状态价值 |
| explained_variance | 1−Var(returns−old_values)/Var(returns)，使用 rollout 更新前预测 | 不是更新后 Critic 的独立测试得分 |
| grad_norm | clip_grad_norm_ 返回的裁剪前范数，再平均 | 大于 0.5 不证明未执行梯度裁剪 |
| episodes | 本轮完整 episode 数 | 不等于环境 transitions |
| steps_per_second | 本进程训练段累计 transitions／累计耗时 | 不是策略质量，续训前后计时起点不同 |

补充说明：

- 当前奖励普通步骤为 0，首次胜利为 1+0.5×剩余 HP 比例，失败／hard timeout 为 0，gamma=1。
  回报图中的约 1.4 是逐局回报均值，不是每个动作即时拿到 1.4。
- 合法动作数随状态变化；均匀策略的熵上限为 ln(K)。只有一个合法动作时熵必为 0。
  训练批熵变化同时受到所访问状态、mask 和策略偏好影响；固定状态对照才能更好隔离策略变化。
- EV 的 returns 是 GAE 优势加 old value 得到的目标，lambda=0.95 时通常不是纯 Monte Carlo RTG。
  方差为零时实现记 None，writer 跳过该点；不要填成 0。小目标方差会使 EV 敏感，但本次负值原因
  尚未独立定位。先看目标／残差方差再归因，不宣称已证明 Critic 失效或 value head 必须重做。
- value_loss 与 EV 的预测时点、目标处理、聚合不同，不宜直接互相判定矛盾。
- HP、turns、steps 等开发统计从 diagnostic JSON 读取；不能假设 TensorBoard 已写入这些 tag。

给用户一个未演示过的局部区间，请其说出“一条观察、一个可能解释、一项需要补充的证据”。
再看固定开发集 before/after 与分遭遇结果，区分训练曲线、开发评估和正式评估。
不为曲线转折编造某轮学会某张牌的故事，除非实际行为证据支持。

## 7. C：最后追踪一次更新

用户能读行为和两三条曲线后才展开，不要一开始堆公式。
使用现有两步数学例子，依次让用户预测奖励、return、TD 残差、GAE 的方向或数值。
然后沿代码追踪：1024 个 rollout 样本 → GAE／value target → 4 个 minibatch×4 epoch → Adam。

强调保留原 observation／action mask、动作、old logprob、old value；掩码后分布参与梯度。
真终止不自举；外部截断用 reset 前最终观测自举，GAE 不跨 reset。
Actor 输出 logits，环境 mask 后变为概率；Critic 输出整个状态的 V(s)，不是各动作 Q(s,a)。
Adam 更新共享主干和输出头的参数，logits 是重新前向的结果，不是优化器直接存储并更新的参数。

总损失的准确符号为：

```text
loss = policy_loss + 0.5 * value_loss - 0.01 * entropy
```

这里 value_loss 内部已经有 0.5 系数；熵以负号进入最小化目标。
共享参数、优势归一化与 clipping 会影响更新，不能保证每个正原始优势样本的动作概率都上升。
如需展示一次真实参数更新，使用隔离副本，明确这是新教学实验并先确认其新增范围；
历史 checkpoint 通常不足以直接恢复每个历史 minibatch 的全部中间量，不冒充原训练逐步记录。
